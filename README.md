# 🍦 Icecream Browser

Welcome to Icecream Browser!

A colourful browser-style website made with Python and Streamlit.

## Features

- Everyday theme
- Diwali theme
- Christmas theme
- Holi theme
- Search & Ask: Icecream AI answers right on the page, with Google results one tap away
- Ice cream riddles
- Animated rainbow ice-cream magic

## AI Chat Setup

Online, the chat uses Google Gemini. Add your key in the Streamlit app's
**Settings → Secrets**:

```toml
GEMINI_API_KEY = "your-key-here"
```

Without a key (for example on your own computer), the chat uses Ollama instead.
